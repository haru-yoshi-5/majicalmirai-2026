============================================================

# 夜の部：歌灯りの御殿屋台

## Magical Mirai 2026 Programming Contest Project Spec

============================================================

## 1. 作品概要

本作品は、マジカルミライ2026 プログラミングコンテスト向けのWebリリックアプリである。

夜の部では、浜松まつりの夜を彩る「御殿屋台」「提灯」「練り」「夜の熱気」をモチーフにする。

ユーザーは曲開始前に、自分だけの屋台飾りを作る。
曲が始まると、クリックした歌詞が提灯の灯りとなり、御殿屋台を少しずつ照らしていく。
選んだ歌詞によって、提灯の色、屋台の装飾、夜の街、湖面の反射、周囲の人々の熱気が変化する。
曲が進むにつれて、周囲にも他の屋台や提灯が現れ、最後には自分の屋台を中心に、浜松の夜が歌詞の灯りで満たされる。

これは単なる歌詞表示アプリではない。
ユーザーが歌詞に触れることで、言葉が灯りになり、屋台を彩り、夜の街と湖面に歌詞の光が広がっていくリリック体験である。

## 2. タイトル

主タイトル：
歌灯りの御殿屋台

サブコピー：
歌詞を灯して、夜の浜松を進め。

補助コピー：
選んだ言葉が提灯となり、祭りの夜を照らす。

## 3. 一文コンセプト

自分で作った御殿屋台を、クリックした歌詞から生まれる提灯の灯りで彩り、最後に選んだ歌詞から屋台の名前が生まれるリリックアプリ。

## 4. 体験の核

本作品の中心体験は以下である。

1. 曲開始前に自分だけの屋台飾りを作る
2. 曲中に歌詞をクリックする
3. クリックした歌詞が光の粒になる
4. 光の粒が提灯に宿る
5. 提灯が灯り、屋台の一部を照らす
6. 選んだ歌詞によって屋台、街、湖面、群衆の雰囲気が変わる
7. 歌詞を選ぶほど、周囲にも提灯や屋台の灯りが増える
8. サビで提灯が一斉に灯り、御殿屋台が夜の街を進む
9. 曲の最後に、最後にクリックした歌詞から屋台の名前が生まれる

重要：
「歌詞をクリックすると提灯が光る」だけにしない。
必ず、歌詞 → 光の粒 → 提灯 → 屋台の装飾 → 夜の街と湖面の反射、という変換体験を作る。

## 5. 企画意図

浜松まつりの夜は、御殿屋台と提灯の光が街を彩る。
本作品では、その夜の華やかさを、歌詞に触れるリリック体験として再構成する。

昼の部が「歌詞から湖風を起こし、凧を揚げる」体験なら、夜の部は「歌詞から灯りを生み、屋台を進める」体験である。

湖は夜の部でも背景ではない。
提灯の光や歌詞の光を映し、音楽の響きとともに揺れる反射の舞台である。

屋台は単なる表示物ではない。
ユーザーが開始前に飾りを選び、曲中の歌詞で灯し、最後に名前を持つ作品である。

## 6. 全体構成

夜の部「歌灯りの御殿屋台」を主実装対象とする。

将来的に昼の部とタイトル画面で選択できる構成にしてもよい。

将来的な構成案：

- 昼の部：湖風の歌詞凧
- 夜の部：歌灯りの御殿屋台

ただし、夜の部単体でも成立するように作る。

## 7. 画面遷移

### 7.1 タイトル画面

表示内容：

- タイトル「歌灯りの御殿屋台」
- サブコピー「歌詞を灯して、夜の浜松を進め。」
- 開始ボタン

開始ボタンを押すと、屋台づくり画面へ進む。

### 7.2 屋台づくり画面

曲開始前に、ユーザーがオリジナルの屋台飾りを作る。

選べる要素：

- 屋台の基調色
- 提灯の色
- 屋台幕の紋様
- 願いの文字

複雑なエディタにはしない。
10秒程度で選べるシンプルな屋台づくりにする。

#### 屋台の基調色

選択肢：

- 朱
- 金
- 藍
- 紫
- 白木

#### 提灯の色

選択肢：

- 暖色
- 青白
- 桃色
- 金色
- 虹色

#### 屋台幕の紋様

選択肢：

- 波紋
- 音
- 星
- 花
- 風

#### 願いの文字

選択肢：

- 歌
- 光
- 夢
- 未来
- 響

屋台づくりが終わったら「この屋台で夜へ」ボタンを押して曲再生画面へ進む。

### 7.3 曲再生画面

作成した屋台が夜の湖畔、または夜の街道に現れる。

画面構成：

- 上部：夜空、星、遠くの提灯
- 中央：自分の御殿屋台、提灯、幕、装飾
- 下部：湖面または濡れた石畳の反射
- 前景：現在の歌詞
- 奥：周囲の屋台、群衆の影、提灯列
- 下部または隅：控えめなプレイヤーUI

### 7.4 エンディング画面

曲終了時に、完成した屋台を表示する。

表示内容：

- あなたが灯した屋台
- 生成された屋台の名前
- 最後に選んだ歌詞
- この屋台を灯した言葉として、選んだ歌詞一覧
- もう一度体験するボタン
- タイトルへ戻るボタン

例：

あなたが灯した屋台

「光ひびく歌灯り屋台」

最後に選んだ歌詞：
光へ響いて

この屋台を灯した言葉：
歌、光、夢、未来

## 8. 屋台づくり仕様

### 8.1 yataiConfig

屋台づくりの結果を yataiConfig として保持する。

yataiConfig に含める情報：

- baseColor
- lanternColor
- pattern
- wish

例：
baseColor: "gold"
lanternColor: "warm"
pattern: "sound"
wish: "歌"

### 8.2 屋台づくりの選択が曲中演出に与える影響

屋台づくりの選択は、見た目だけでなく曲中の演出にも影響させる。

紋様ごとの影響：

- 波紋：湖面や石畳への光の反射が大きくなる
- 音：提灯の光が音波のように広がる
- 星：夜空と屋台周辺に星粒が増える
- 花：サビで光の花が咲く
- 風：提灯が大きく揺れ、光の軌跡が流れる

提灯色ごとの影響：

- 暖色：祭りらしい温かい雰囲気になる
- 青白：湖のソナーレらしい涼やかな雰囲気になる
- 桃色：華やかでやわらかい雰囲気になる
- 金色：御殿屋台の豪華さが増す
- 虹色：サビで色変化が大きくなる

願いの文字は、何も歌詞を選ばなかった場合の屋台名生成にも使う。

## 9. 歌詞選択仕様

### 9.1 基本動作

曲中に表示される歌詞をクリックできるようにする。

クリック時に起きること：

1. クリックされた歌詞を selectedLyrics に保存する
2. クリックされた歌詞が光の粒になる
3. 光の粒が屋台の提灯へ飛ぶ
4. 提灯が灯る
5. 屋台の装飾や幕が少しずつ明るくなる
6. 湖面や石畳に提灯の光が反射する
7. 選んだ歌詞の分類に応じて、屋台、街、夜空、湖面の雰囲気が変わる
8. 周囲に小さな提灯や別の屋台の灯りが現れる

### 9.2 selectedLyrics

selectedLyrics は、ユーザーが曲中にクリックした歌詞の履歴である。

保持する情報：

- text
- time
- category
- position
- selectedAt

selectedLyrics の最後の要素は、エンディングで屋台の名前生成に使う。

## 10. 歌詞分類

選ばれた歌詞を簡易的に分類し、演出と名前生成に反映する。

### bright

対象語：

- 光
- 未来
- 夢
- 希望

演出：

- 提灯の光が強くなる
- 屋台の金装飾が輝く
- 湖面反射が明るくなる

### sound

対象語：

- 声
- 歌
- 響く
- 音
- ソナーレ

演出：

- 光が音波のように広がる
- 提灯列がリズムに合わせて揺れる
- 屋台幕に五線譜風の光が走る

### festival

対象語：

- 祭り
- 灯り
- 夜
- 街
- 進む

演出：

- 群衆の影が増える
- 周囲の屋台や提灯が増える
- 屋台が前へ進む感じが強くなる

### deep

対象語：

- 涙
- 迷い
- 静か
- 闇

演出：

- 夜の色が深くなる
- 提灯の周囲に静かな余韻が出る
- 反射がゆっくり揺れる

### wish

対象語：

- 星
- 願い
- 祈り

演出：

- 夜空に星粒が増える
- 提灯の周囲に光輪が出る
- 遠くの灯りがやわらかく増える

### neutral

上記に該当しない語。

演出：

- 標準の提灯点灯
- 標準の屋台装飾
- 標準の反射

## 11. 自分の屋台の演出

自分の屋台は画面の主役である。

自分の屋台のルール：

- 周囲の屋台より大きく表示する
- 画面中央付近に配置する
- 色と紋様は yataiConfig を反映する
- 歌詞を選ぶたびに提灯が増える、または灯る
- 屋台幕や装飾に歌詞が刻まれる
- 曲の進行に合わせて少しずつ前へ進む
- サビで提灯が一斉に灯る
- ラストで完成した姿として表示される

屋台に反映される要素：

- 選んだ歌詞
- 歌詞分類に応じた提灯色や光
- yataiConfig の願い文字
- yataiConfig の紋様

描画はCanvasまたはPixiJSでよい。
MVPでは精密な御殿屋台の描画は不要。
屋根、車輪、提灯、幕、金の装飾、シルエットで御殿屋台らしさが伝わればよい。

## 12. 提灯と光の演出

提灯は、歌詞を灯りへ変換する装置である。

歌詞クリック時の流れ：

1. 歌詞が光の粒になる
2. 光の粒が提灯へ飛ぶ
3. 提灯がふわっと灯る
4. 光が屋台の装飾へ広がる
5. 湖面や石畳に反射する
6. 周囲の提灯や屋台も少し反応する

提灯の表現：

- やわらかい発光
- ゆっくり揺れる
- 文字が浮かぶ
- サビで一斉点灯する
- 歌詞分類によって色味が変わる

反射の表現：

- 湖面または濡れた石畳に光が伸びる
- 提灯の灯りがゆらゆら揺れる
- 屋台の輪郭がぼんやり映る
- 「湖のソナーレ」との接続を出すため、光が水面に響くように広がる

## 13. 周囲の屋台・提灯の演出

ユーザーが歌詞を選ぶほど、周囲にも他の人が灯したような提灯や、遠くの屋台が現れる。

重要：
主役はユーザー自身の屋台である。
周囲の屋台や提灯は背景演出として扱い、自分の屋台を邪魔しないようにする。

### 13.1 周囲の灯りのルール

- 開始時は自分の屋台だけ、または周囲はほぼ暗い
- 歌詞を選ぶたびに、遠くに小さな提灯が少しずつ灯る
- 選んだ歌詞の分類によって、出現する灯りの色や動きが変わる
- サビでは周囲の提灯も一斉に明るくなる
- finalChorusでは夜の街いっぱいに提灯と屋台の光が広がる
- アウトロでは自分の屋台を中央に、周囲の灯りを遠景に配置し、完成した祭りの夜として見せる

### 13.2 周囲の灯りの見た目

- 自分の屋台より小さい
- 遠景として少し淡く表示
- 提灯の列や屋台のシルエットとして見せる
- それぞれ色や高さが違う
- ゆっくり揺れる
- 湖面や石畳に薄く反射させる

### 13.3 communityLantern

周囲の提灯を communityLantern として管理する。

communityLantern に含める情報：

- id
- x
- y
- size
- color
- word
- phase
- opacity
- type

周囲の灯りは、実際のオンラインデータでなくてよい。
まずは選択された歌詞や mockLyrics から自動生成する。

### 13.4 communityYatai

周囲の屋台を communityYatai として管理してもよい。

communityYatai に含める情報：

- id
- x
- y
- scale
- color
- lanternCount
- opacity
- phase

MVPでは communityLantern のみでもよい。
周囲の屋台は Phase 2 で追加してもよい。

## 14. 屋台の名前生成

曲終了時に、最後にクリックした歌詞をもとに、完成した屋台の名前を自動生成する。

### 14.1 基本ルール

- selectedLyrics の最後の要素を lastSelectedLyric とする
- lastSelectedLyric と yataiConfig.pattern を使って yataiName を生成する
- 何も歌詞をクリックしていない場合は yataiConfig.wish を使う
- それもない場合は「歌灯りの御殿屋台」を使う

### 14.2 patternName

yataiConfig.pattern ごとの接尾語：

- 波紋 → 波紋屋台
- 音 → 音灯り屋台
- 星 → 星灯り屋台
- 花 → 花灯り屋台
- 風 → 風灯り屋台

### 14.3 名前生成テンプレート

歌詞分類ごとの名前テンプレート：

bright：
「{keyword}を灯す{patternName}」

sound：
「{keyword}ひびく{patternName}」

festival：
「{keyword}を運ぶ{patternName}」

deep：
「{keyword}を抱く{patternName}」

wish：
「{keyword}を結ぶ{patternName}」

neutral：
「ことばを灯す{patternName}」

### 14.4 名前生成例

- 最後の歌詞が「光」かつ紋様が「音」 → 「光を灯す音灯り屋台」
- 最後の歌詞が「声」かつ紋様が「波紋」 → 「声ひびく波紋屋台」
- 最後の歌詞が「夢」かつ紋様が「星」 → 「夢を灯す星灯り屋台」
- 最後の歌詞が「夜」かつ紋様が「花」 → 「夜を運ぶ花灯り屋台」
- 最後の歌詞が「願い」かつ紋様が「風」 → 「願いを結ぶ風灯り屋台」
- 分類できない歌詞 → 「ことばを灯す〇〇屋台」

実装では、utils/generateYataiName.ts を作成する。
引数は lastSelectedLyric と yataiConfig を想定する。
EndingOverlay で生成された yataiName を表示する。
最後にクリックした歌詞も表示する。

重要：
屋台の名前は、ユーザーが最後に選んだ歌詞によって変わるようにする。
これにより、曲の終わり際にどの歌詞を選ぶかが、完成した屋台の意味に影響する。

## 15. 曲進行と演出

TextAlive連携前は、モックプレイヤーで曲時間を管理する。

仮の曲構成：

- intro
- verse
- preChorus
- chorus
- bridge
- finalChorus
- outro

### intro

- 夜の湖畔または夜の街道
- 自分の屋台はまだ暗い
- 提灯は数個だけ弱く灯っている
- 周囲は静か

### verse

- 歌詞が表示される
- 歌詞をクリックすると提灯が1つ灯る
- 屋台の装飾が少し見える
- 遠くに小さな提灯が1〜2個現れ始める

### preChorus

- 提灯の数が増える
- 湖面や石畳への反射が強くなる
- 周囲の灯りが少し増える
- 屋台がゆっくり進み始める

### chorus

- 提灯が一斉に灯る
- 自分の屋台が大きく明るくなる
- 周囲の提灯も一斉に明るくなる
- 夜空や湖面に光が広がる
- 屋台幕や金装飾が光る

### bridge

- 一度静かになる
- 湖面に屋台と提灯の反射が映る
- 選んだ歌詞が提灯や幕に浮かぶ
- 遠くの灯りがゆっくり揺れる

### finalChorus

- これまでに灯した提灯がすべて強く光る
- 自分の屋台が最も華やかになる
- 夜の街いっぱいに提灯と屋台の光が広がる
- 光の波が湖面に響く
- 祭りの夜の完成感を出す

### outro

- 完成した自分の屋台を中央に見せる
- 周囲の灯りを遠景に配置する
- 湖面または石畳に光の反射を映す
- エンディング表示へ移行する

## 17. モックプレイヤー

TextAlive連携前でも動作確認できるように、モックプレイヤーを実装する。

必要な機能：

- 再生
- 一時停止
- リセット

## 18. 技術構成

このプロジェクトは Vite+ 環境で実装する。

前提：

- 通常のViteプロジェクトだと決めつけない
- Vite+の設定、package.json、既存ディレクトリ構成を確認する
- 既存のVite+構成を壊さない
- 起動、ビルド、チェックのコマンドは package.json と Vite+ 設定から判断する
- npm run dev 固定にしない
- vp コマンドが利用されている場合は、その構成に従う

推奨：

- Vite+
- Vanilla TypeScript
- PixiJS または Canvas API
- DOM UIは最小限
- 外部ライブラリは必要最小限

Reactは必須ではない。
本作品はUIコンポーネント中心ではなく、提灯、屋台、光、反射、粒子、歌詞同期などのリアルタイム2D演出が主役である。

## 22. 実装時の注意

- まず動くMVPを作る
- 夜の見た目のインパクトを重視する
- 自分の屋台を必ず主役にする
- 周囲の提灯や屋台は主役を邪魔しない
- 歌詞クリックの意味を「灯りをともすこと」として明確にする
- 湖は背景ではなく、灯りと音楽を反射する舞台として表現する
- スコア、コンボ、ミス判定など音ゲー要素は入れない
- UIは祭りの夜の体験を邪魔しない
- アニメーションは requestAnimationFrame または PixiJS ticker で行う
- UIフレームワークのstate更新で毎フレーム再レンダリングしすぎない
- 描画オブジェクトは可能なら内部状態で管理する
- イベントリスナーはクリーンアップする
- 画面リサイズに対応する
- クリック座標と描画座標がずれないようにする
- Vite+の既存設定を勝手に変更しない
- フォーマッタ、リンタ、型チェックはVite+側の推奨コマンドがあればそれに従う
