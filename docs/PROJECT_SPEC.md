# 湖風の歌詞凧
## Magical Mirai 2026 Programming Contest Project Spec

---

## 1. 作品概要

本作品は、マジカルミライ2026 プログラミングコンテスト向けのWebリリックアプリである。

マジカルミライ2026の浜松開催と、浜松まつりの凧揚げ文化、そして2026年テーマ「湖のソナーレ」を掛け合わせた、昼の部を中心としたリリックアプリとして制作する。

ユーザーは曲開始前に、自分だけのオリジナル凧を作る。
曲が始まると、選んだ歌詞が湖に落ち、波紋となり、その波紋が湖風へと変わって凧を押し上げる。
選んだ歌詞によって、空、湖、風、凧、周囲の雰囲気が変化する。
曲が進むにつれて、周囲にも他の人が作ったような凧や、歌詞から生まれた凧が現れ、最後には自分の凧を中心にたくさんの凧が浜松の空を彩る。

これは単なる歌詞表示アプリではない。
ユーザーが歌詞に触れることで、湖から風が生まれ、自分の凧とみんなの凧が空へ揚がっていく、創作と祭りのリリック体験である。

## 2. タイトル

主タイトル：
湖風の歌詞凧

サブコピー：
歌詞の風で、祭りの空が広がっていく。

補助コピー：
湖から吹く風が、歌詞を空へ運ぶ。

## 3. 一文コンセプト

自分で作った凧を、クリックした歌詞から生まれる湖風で空へ揚げ、最後に選んだ歌詞から凧の名前が生まれるリリックアプリ。

## 4. 体験の核

本作品の中心体験は以下である。

1. 曲開始前に自分だけの凧を作る
2. 曲中に歌詞をクリックする
3. クリックした歌詞が湖に落ちる
4. 湖面に波紋が広がる
5. 波紋が風の流線へ変わる
6. 湖風が凧を押し上げる
7. 選んだ歌詞によって空、湖、風、凧の雰囲気が変わる
8. 歌詞を選ぶほど、周囲にも小さな凧が現れる
9. サビで自分の凧と周囲の凧が一斉に舞い上がる
10. 曲の最後に、最後にクリックした歌詞から凧の名前が生まれる

重要：
「歌詞をクリックすると凧に文字が描かれる」だけにしない。
必ず、歌詞 → 湖面の波紋 → 湖風 → 凧が揚がる、という変換体験を作る。

## 5. 企画意図

浜松まつりの凧揚げは、自分の凧だけでなく、多くの凧が空を彩る風景が魅力である。
本作品では、ユーザーが作った凧を主役にしつつ、歌詞から生まれる湖風によって周囲にも"みんなの凧"が現れる。

これにより、個人の歌詞体験が、マジカルミライに集まる創作の広がりや、浜松まつりのにぎわいへつながっていく感覚を表現する。

湖は単なる背景ではない。
歌詞を受け止め、波紋を生み、風へ変換する装置である。

凧は単なる表示物ではない。
ユーザーが開始前に作り、歌詞の風を受けて成長し、最後に名前を持つ作品である。

## 6. 全体構成

現時点では昼の部「湖風の歌詞凧」を主実装対象とする。

将来的に夜の部を追加できる構造にしてもよいが、MVPでは昼の部を優先する。

将来的な構成案：
- 昼の部：湖風の歌詞凧
- 夜の部：歌灯りの屋台

ただし、MVPでは夜の部は必須ではない。
まず昼の部を高い完成度で作る。

## 7. 画面遷移

### 7.1 タイトル画面

表示内容：
- タイトル「湖風の歌詞凧」
- サブコピー「歌詞の風で、祭りの空が広がっていく。」
- 開始ボタン

開始ボタンを押すと、凧づくり画面へ進む。

### 7.2 凧づくり画面

曲開始前に、ユーザーがオリジナル凧を作る。

選べる要素：
- 凧の形
- メインカラー
- 紋様
- 願いの文字

複雑なエディタにはしない。
10秒程度で選べるシンプルな凧づくりにする。

#### 凧の形

選択肢：
- 大凧
- 菱形
- 風切り

#### メインカラー

選択肢：
- 青
- 赤
- 白
- 紫
- 金

#### 紋様

選択肢：
- 波紋
- 風
- 星
- 音

#### 願いの文字

選択肢：
- 未来
- 歌
- 光
- 夢

凧づくりが終わったら「この凧で空へ」ボタンを押して曲再生画面へ進む。

### 7.3 曲再生画面

作成した凧が湖の上に低く浮かぶ。

画面構成：
- 上部：空、雲、遠くの凧
- 中央：自分の凧、凧糸、風の流線
- 下部：湖、波紋、歌詞が落ちる場所
- 前景：現在の歌詞
- 下部または隅：控えめなプレイヤーUI

### 7.4 エンディング画面

曲終了時に、完成した凧を表示する。

表示内容：
- あなたが揚げた凧
- 生成された凧の名前
- 最後に選んだ歌詞
- この凧を起こした風として、選んだ歌詞一覧
- もう一度体験するボタン
- タイトルへ戻るボタン

例：

あなたが揚げた凧

「未来を運ぶ風凧」

最後に選んだ歌詞：
未来へ広がって

この凧を起こした風：
未来、声、空、光

## 8. 凧づくり仕様

### 8.1 kiteConfig

凧づくりの結果を kiteConfig として保持する。

kiteConfig に含める情報：
- shape
- color
- pattern
- wish

例：
shape: "large"
color: "blue"
pattern: "wind"
wish: "未来"

### 8.2 凧づくりの選択が曲中演出に与える影響

凧づくりの選択は、見た目だけでなく曲中の演出にも影響させる。

紋様ごとの影響：
- 波紋：湖面の波紋が少し大きくなる
- 風：風の流線が強くなる
- 星：歌詞選択時に星粒が増える
- 音：波紋が音波や五線譜風になる

色ごとの影響：
- 青：空と湖が澄んだ雰囲気になる
- 赤：サビ時に熱気が増す
- 白：光粒が上品に増える
- 紫：幻想的な夕暮れ感が出る
- 金：祭りの華やかさ、光の縁取りが増える

願いの文字は、何も歌詞を選ばなかった場合の凧名生成にも使う。

## 9. 歌詞選択仕様

### 9.1 基本動作

曲中に表示される歌詞をクリックできるようにする。

クリック時に起きること：
1. クリックされた歌詞を selectedLyrics に保存する
2. クリックされた歌詞が湖へ落ちる演出を出す
3. 湖面に波紋を発生させる
4. 波紋が風の流線へ変わる
5. 自分の凧が少し上昇する
6. 凧に歌詞の模様や文字が刻まれる
7. 空、湖、風、凧の雰囲気が変化する
8. 周囲に小さな凧が現れる、または既存の凧が高く舞う

### 9.2 selectedLyrics

selectedLyrics は、ユーザーが曲中にクリックした歌詞の履歴である。

保持する情報：
- text
- time
- category
- position
- selectedAt

selectedLyrics の最後の要素は、エンディングで凧の名前生成に使う。

## 10. 歌詞分類

選ばれた歌詞を簡易的に分類し、演出と名前生成に反映する。

分類例：

### bright
対象語：
- 未来
- 夢
- 光
- 希望

演出：
- 空が明るくなる
- 光粒が増える
- 凧が高く上がる
- 凧に明るい模様が入る

### sound
対象語：
- 声
- 歌
- 響く
- 音
- ソナーレ

演出：
- 波紋が音波風になる
- 凧糸が五線譜のように揺れる
- 風の線がリズムを持つ

### airy
対象語：
- 空
- 風
- 飛ぶ
- 舞う

演出：
- 風の流線が強くなる
- 雲が流れる
- 凧が大きく舞う

### deep
対象語：
- 夜
- 涙
- 迷い
- 静か

演出：
- 湖が深い青になる
- 静かな余韻が出る
- 凧に濃い模様が入る

### wish
対象語：
- 星
- 願い
- 祈り

演出：
- 空に星粒が出る
- 凧の周囲に光輪が出る
- 遠くの凧がやわらかく光る

### neutral
上記に該当しない語。

演出：
- 標準の波紋
- 標準の風
- 標準の凧上昇

## 11. 自分の凧の演出

自分の凧は画面の主役である。

自分の凧のルール：
- 周囲の凧より大きく表示する
- 画面中央付近に配置する
- 色と紋様は kiteConfig を反映する
- 歌詞を選ぶたびに模様や文字が増える
- 風を受けて揺れる
- 曲の進行に合わせて上昇する
- サビで大きく舞う
- ラストで完成した姿として表示される

凧に刻まれる要素：
- 選んだ歌詞
- 歌詞分類に応じた模様
- kiteConfig の願い文字
- kiteConfig の紋様

描画はCanvasまたはSVGでよい。
MVPでは複雑な凧描画は不要。
形、色、紋様、文字、揺れが伝わればよい。

## 12. 湖と風の演出

湖は、歌詞を風に変換する装置である。

歌詞クリック時の流れ：
1. 歌詞が湖に落ちる
2. 湖面に波紋が広がる
3. 波紋がほどける
4. 上方向の風の流線に変わる
5. 風が凧を押し上げる

湖の表現：
- 画面下部に配置
- 水面の反射
- 波紋
- 光のきらめき
- 凧の反射
- 周囲の凧の薄い反射

風の表現：
- 上方向に流れる曲線
- 半透明の白、シアン、金など
- 歌詞分類によって色や強さを変える
- サビで風の量を増やす
- finalChorusで大きな風の渦を作る

## 13. 周囲の凧の演出

ユーザーが歌詞を選ぶほど、周囲にも他の人が作ったような凧、または歌詞から生まれた凧が現れる。

重要：
主役はユーザー自身の凧である。
周囲の凧は背景演出として扱い、自分の凧を邪魔しないようにする。

### 13.1 周囲の凧のルール

- 開始時は自分の凧だけ
- 歌詞を選ぶたびに、遠くに小さな凧が少しずつ現れる
- 選んだ歌詞の分類によって、出現する周囲の凧の色や模様が変わる
- サビでは周囲の凧も一斉に高く舞い上がる
- finalChorusでは空いっぱいに凧が増え、祭りの空のような印象にする
- アウトロでは自分の凧を中央に、周囲の凧を遠景に配置し、完成した祭りの空として見せる

### 13.2 周囲の凧の見た目

- 自分の凧より小さい
- 遠景として少し淡く表示
- それぞれ色や形が違う
- 小さな文字や記号が入っている
- 風に合わせてゆっくり揺れる
- 必要なら湖面に薄く反射させる

### 13.3 communityKite

周囲の凧を communityKite として管理する。

communityKite に含める情報：
- id
- x
- y
- size
- color
- pattern
- word
- phase
- opacity
- type

周囲の凧は、実際のオンラインデータでなくてよい。
まずは選択された歌詞や mockLyrics から自動生成する。

### 13.4 将来的な追加案

Phase 2以降で、曲終了時に自分の凧データを localStorage に保存し、次回プレイ時に過去の自分の凧を周囲の凧として表示できるようにしてもよい。

ただしMVPでは必須ではない。

## 14. 凧の名前生成

曲終了時に、最後にクリックした歌詞をもとに、完成した凧の名前を自動生成する。

### 14.1 基本ルール

- selectedLyrics の最後の要素を lastSelectedLyric とする
- lastSelectedLyric と kiteConfig.pattern を使って kiteName を生成する
- 何も歌詞をクリックしていない場合は kiteConfig.wish を使う
- それもない場合は「湖風の歌詞凧」を使う

### 14.2 patternName

kiteConfig.pattern ごとの接尾語：
- 波紋 → 波紋凧
- 風 → 風凧
- 星 → 星凧
- 音 → 音凧

### 14.3 名前生成テンプレート

歌詞分類ごとの名前テンプレート：

bright：
「{keyword}を運ぶ{patternName}」

sound：
「{keyword}ひびく{patternName}」

airy：
「{keyword}へ舞う{patternName}」

deep：
「{keyword}を抱く{patternName}」

wish：
「{keyword}を結ぶ{patternName}」

neutral：
「ことばを乗せる{patternName}」

### 14.4 名前生成例

- 最後の歌詞が「未来」かつ紋様が「風」 → 「未来を運ぶ風凧」
- 最後の歌詞が「声」かつ紋様が「音」 → 「声ひびく音凧」
- 最後の歌詞が「光」かつ紋様が「星」 → 「光を結ぶ星凧」
- 最後の歌詞が「夢」かつ紋様が「波紋」 → 「夢を広げる波紋凧」
- 最後の歌詞が「空」かつ紋様が「風」 → 「空へ舞う風凧」
- 分類できない歌詞 → 「ことばを乗せる〇〇凧」

実装では、utils/generateKiteName.ts を作成する。
引数は lastSelectedLyric と kiteConfig を想定する。
EndingOverlay で生成された kiteName を表示する。
最後にクリックした歌詞も表示する。

重要：
凧の名前は、ユーザーが最後に選んだ歌詞によって変わるようにする。
これにより、曲の終わり際にどの歌詞を選ぶかが、完成した凧の意味に影響する。

## 15. 曲進行と演出

TextAlive連携前は、モックプレイヤーで曲時間を管理する。

仮の曲構成：
- intro
- verse
- preChorus
- chorus
- bridge
- finalChorus
- outro

### intro

- 静かな湖
- 自分の凧が低く浮いている
- 周囲の凧はまだ出ない
- 風は弱い

### verse

- 歌詞が表示される
- 歌詞をクリックすると小さな湖風が起きる
- 自分の凧が少しずつ上がる
- 遠くに小さな凧が1〜2枚現れ始める

### preChorus

- 湖面の波紋が増える
- 風の流線が強くなる
- 周囲の凧が少し増える
- 雲が流れ始める

### chorus

- 湖面の波紋が一斉に風になる
- 自分の凧が大きく舞い上がる
- 周囲の凧も一斉に高く上がる
- 空が明るくなる
- 凧糸や風の流線が光る

### bridge

- 一度静かになる
- 湖に凧の反射が映る
- 選んだ歌詞が凧の模様として見える
- 遠くの凧がゆっくり揺れる

### finalChorus

- これまでに生まれた風が合流する
- 自分の凧が最も高く舞う
- 空いっぱいに周囲の凧が広がる
- 凧糸や風の線が大きな渦を描く
- 祭りの空の完成感を出す

### outro

- 完成した自分の凧を中央に見せる
- 周囲の凧を遠景に配置する
- 湖面に凧の反射を映す
- エンディング表示へ移行する

## 18. 技術構成

このプロジェクトは Vite+ 環境で実装する。

前提：
- 通常のViteプロジェクトだと決めつけない
- Vite+の設定、package.json、既存ディレクトリ構成を確認する
- 既存のVite+構成を壊さない
- 起動、ビルド、チェックのコマンドは package.json と Vite+ 設定から判断する
- npm run dev 固定にしない
- vp コマンドが利用されている場合は、その構成に従う

実装方針（本プロジェクトでの確定事項）：
- Vite+ (`vp` CLI) + TypeScript の **Vanilla** 構成
- 2Dリアルタイム描画は **PixiJS** を使う
- DOM はタイトル画面・凧づくりUI・プレイヤーUI・エンディングUI など最小限
- `scene = "title" | "setup" | "playing" | "ending"` で画面状態を管理
- アニメーションは PixiJS の ticker、必要に応じて `requestAnimationFrame`
- TextAlive 連携は後から追加しやすいよう `state/TextAliveController.ts` として分離する
- MVPでは mockLyrics と mockPlayer で動作確認する

外部ライブラリは必要最小限にする。
まずは PixiJS と既存フレームワーク（Vite+ / TS）だけで MVP を作る。

```
    generateCommunityKite.ts    // 周囲の凧の自動生成
```

新規ファイルを足すときも、Canvas/PixiJS 描画は `scenes/DayKiteScene.ts` に集約し、UI/HTML 側のクリック・表示は `components/*` 側に置く責務分離を守る。

## 22. 実装時の注意

- まず動くMVPを作る
- 画面インパクトを重視する
- 自分の凧を必ず主役にする
- 周囲の凧は主役を邪魔しない
- 歌詞クリックの意味を「風を起こすこと」として明確にする
- 湖は背景ではなく、歌詞を風に変える装置として表現する
- スコア、コンボ、ミス判定など音ゲー要素は入れない
- UIは祭りと空の体験を邪魔しない
- PixiJS の ticker で描画ループを回す
- 毎フレームの DOM 操作は避け、PixiJS 内部状態で完結させる
- イベントリスナーはクリーンアップする
- 画面リサイズに対応する
- クリック座標と PixiJS ステージ座標がずれないようにする
- Vite+ の既存設定を勝手に変更しない
- フォーマッタ、リンタ、型チェックは `vp check` に従う

## 23. 避けること

- ただの凧カスタマイズアプリ

- 浜松まつり紹介だけのアプリ
- 湖が背景にしか見えない構成
- 自分の凧より周囲の凧が目立つ構成

- Vite+構成を壊す大規模変更

- 湖から空へ歌詞が運ばれる感覚

## 25. 最重要方針

この作品は、ただの歌詞表示アプリではない。

ユーザーが作った凧を、歌詞から生まれる湖風で空へ揚げるリリック体験である。

実装中に迷ったら、以下を優先する。

1. 自分で作った凧を揚げる体験
2. 歌詞 → 湖の波紋 → 風 → 凧上昇 の変換
3. 浜松まつりの凧揚げらしさ
4. 2026テーマ「湖のソナーレ」との接続
5. 周囲の凧による祭りの空の広がり
6. 最後にクリックした歌詞から凧の名前が生まれること
7. Vite+の既存構成を尊重すること
